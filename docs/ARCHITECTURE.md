# Architecture

This document describes the architecture decided in `SYSTEM_PROMPT.md` and marks
what exists today. **Currently implemented: the application shell, CI, the
tool-aware health route, and the typed EDL contract.**

## Decided design

- **Non-destructive editing.** The frontend never touches video bytes. It edits a
  small JSON document, the Edit Decision List (EDL). The backend turns the EDL
  into one FFmpeg command. Times are integer frames with a rational fps.
- **Contract first.** `contract/edl.schema.json` is the EDL source of truth.
  FastAPI generates `contract/openapi.json`; the frontend generates its types from it.
- **Pure core.** Domain logic (EDL validation, frame/time math, FFmpeg argument
  building, progress math) lives in `backend/app/core/` with no web-framework imports.
- **Stack.** React + Vite + TypeScript + Tailwind; Python 3.11+, FastAPI,
  Pydantic v2, SQLAlchemy 2, Alembic; SQLite locally; external FFmpeg/ffprobe;
  in-process worker threads.
- **Storage and users behind interfaces.** Every table carries `user_id`; every
  repository call requires it; media URLs are issued by the API.

## Repository layout today

```
backend/
  app/main.py        create_app(): FastAPI app, startup tool discovery
  app/config.py      Settings read from environment variables
  app/openapi.py     OpenAPI build (adds the EDL models to components)
  app/contract_gen.py  writes contract/openapi.json
  app/api/health.py  GET /api/v1/health
  app/core/          pure domain logic: edl.py, timecode.py, toolchain.py
  tests/             pytest
contract/
  edl.schema.json    EDL source of truth (hand-written JSON Schema)
  openapi.json       generated; do not edit
frontend/
  src/               React shell; src/api/ holds the typed-fetch helpers
  src/api/schema.d.ts  generated by openapi-typescript; do not edit
scripts/             cross-platform Node scripts: setup, dev, test, license check
docs/                this folder
.github/workflows/   ci.yml
```

Directories from the target layout that have no code yet (`jobs/`,
`storage/`, `db/`, `auth/`, `e2e/`) are created by the packages that need them.

## Development wiring

- `npm run dev` starts uvicorn (`--reload`) and Vite together. Vite proxies
  `/api` to the backend, so the frontend always uses same-origin relative URLs.
- Developer commands are Node scripts using argument lists (never `shell=True`
  on the Python side), so they behave the same in PowerShell and POSIX shells.
- The backend does not use asyncio subprocess APIs; FFmpeg will run through
  `subprocess.Popen` in worker threads (a later package).

## Tool discovery and health

`core/toolchain.py` resolves `FFMPEG_PATH` / `FFPROBE_PATH` before `PATH`, runs
`-version` and `-encoders` once during application startup, and selects the MP4
video encoder. `GET /api/v1/health` only reports that stored result; it never
runs a tool. Missing or broken tools produce `status: "degraded"` with a
`problems` list (`code`, `message`, `hint`), still as HTTP 200, so the UI can
show what to fix. A path set explicitly in `FFMPEG_PATH` that does not work is an
error and never silently falls back to `PATH`.

Encoder order: `libx264`, then `libopenh264`, then `libsvtav1` (AV1 in MP4, with a
note in the response). `h264_nvenc` / `h264_qsv` are used only when
`VIDEOCUT_HARDWARE_ENCODER` names one of them. "Available" means compiled into
FFmpeg; it does not prove the GPU initializes, which a later package reports when
rendering.

## EDL contract and its policies

- `contract/edl.schema.json` holds per-field rules. `core/edl.py` (Pydantic v2,
  strict mode, so `"30"` and `"yes"` are not coerced) enforces the same rules plus
  what a standalone schema cannot express: ordered, non-overlapping segments,
  unique ids, and crop `x + w <= 1`, `y + h <= 1`. Tests run a shared corpus
  through both and pin the cross-field cases only the model rejects.
- Source-dependent rules live in `validate_against_source`: `end <= total_frames`
  and an EDL fps equal to the source fps (compared by value, so `60000/2002`
  matches `30000/1001`).
- **Empty EDL:** valid (the honest state after deleting everything) but not
  exportable; `ensure_exportable` rejects it.
- **Crop:** minimum width and height are 0.05 of the displayed frame.
- **Timecode:** `HH:MM:SS:FF` is non-drop-frame. `FF` counts `round(fps)` frames
  per second and must be below that number, so for 30000/1001 the label runs
  slightly slower than the wall clock, like any non-drop-frame editor. Drop-frame
  `;` separators are rejected.
- `contract/openapi.json` and `frontend/src/api/schema.d.ts` are generated by
  `npm run contract`. `npm test` runs the same generation into a temp directory
  and fails if the committed files differ (drift check, also run by CI).
